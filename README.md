# ktv-frontend

YouTube AI Karaoke Studio (Frontend Client) • Produced by [សំបុករៀន (Sombokrean)](https://www.sombokrean.com/)

## Features
- **Official YouTube IFrame Player API Engine** (Synchronized video & audio controls)
- **Real-Time Synchronized Karaoke Lyrics** in Khmer & English
- **Cyberpunk Sci-Fi HUD Search & Trending Console**
- **Mobile Audio Studio Drawer** with Live Microphone, Echo, Delay & Pitch Controls
- **Cross-Browser & Multi-Device Sync**
- **Optimized for Vercel Deployment**

## Environment Variables
- `VITE_API_URL`: URL of the deployed AI backend (e.g. `https://ytktv-backend.onrender.com`)
